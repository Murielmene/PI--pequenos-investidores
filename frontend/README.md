# Introdução ao Investimento

Projeto React Native Expo SDK 54 para uma experiência inicial de investimento clara e intuitiva.

## Como usar

1. Abra o terminal em `frontend`
2. Rode `npm install`
3. Rode `npm start`
4. Abra no emulador Android/iOS ou no Expo Go

## O que está pronto

- Tela inicial com mensagem de boas-vindas
- Cards de recursos com explicação simples
- Layout leve e acessível

## Estrutura

- `App.tsx` - ponto de entrada do aplicativo
- `src/screens/HomeScreen.tsx` - tela principal
- `src/components/FeatureCard.tsx` - cartão descritivo
- `src/theme.ts` - cores do app
